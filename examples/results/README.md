# MSRC1·2 주소 접기 금지 결과

2026-11-19 로컬에 보관된 원본 우선 후보35개를 전체 파일 단위로 비교한 요약입니다.
원본 트레이스는 배포하지 않습니다. 파일명·요청수·SHA-256은 [JSON 요약](msrc-no-folding-summary.json)에 있습니다.
공식 배포본 hash와 별도 대조한 자료는 아닙니다.

고정 조건은 원시32 GiB SSD×4, OP10%, SSD당 reserve1개, read+write 주소 점유, 주소 접기 금지입니다.
파일을 자르거나 범위 밖 요청만 삭제하지 않으며 원본 전체가 사용자 용량에 들어가는20개 파일을 사용합니다.

| zone = stripe | user zone 전체 | 사용 | 비어 있음 |
| --- | ---: | ---: | ---: |
| 16 MiB | 7,368 | 6,336 | 1,032 |
| 32 MiB | 3,680 | 3,189 | 491 |

reserve4개는 두 경우 모두 목표에서 제외합니다. 적합한 원본을 전부 합쳐도 빈 zone이 남으므로,
이 후보 집합에서 빈 zone0개를 달성하는 조합은 없습니다. 따라서 최소 요청수 완전 cover도 존재하지 않습니다.

32 MiB에서 SSD별 빈 user zone은120/125/123/123개입니다.
16 MiB→32 MiB 재평가에는 기존 raw-address bitmap의 인접 두 bit를 OR하고 새 용량으로 파일 적합성을 다시 검사했습니다.
새 stripe에 맞춰 초기 SSD 배치도 다시 계산합니다.

주소 접기를 허용한 과거 분석은 `usr_2.csv` 단독10,570,046개 요청으로 전체 user zone을 덮었습니다.
하지만 그 결과에는 runtime 주소 접기와 경계 초과 요청이 있어, **현재 주소 접기 금지 조건의 추천으로 사용하지 않습니다.**
